# Custom Timer

A high-precision timer with voice cues, acoustic chimes, and smooth continuous circular progress.

## Features

- **Continuous High-Frequency Timer**: Sub-second precision timer designed for workouts, productivity, and training.
- **Multi-Loop Routines & Tracking**: Configure target loops and track loop progress in real-time.
- **Voice & Chime Feedback**: Speech countdowns, synthesized acoustic chimes, adjustable volume control, and sound testing.
- **Multi-Segment Routines**: Create and customize multiple segments with minute and decimal-second precision.
- **Interactive Time Scrubbing**: Drag or click along the circular progress ring to quickly scrub or adjust time.
- **Multi-Language Support**: Choose your preferred language for voice countdowns.
- **Automatic Persistence**: Automatically saves your custom routines, loop settings, sound preferences, and dark/light theme across sessions.
- **Dynamic Browser Title**: Live tab updates showing countdown time, timer state, and loop progress.
- **Comprehensive Keyboard Shortcuts**:
  - <kbd>Space</kbd>: Start / Pause
  - <kbd>R</kbd>: Reset current interval
  - <kbd>T</kbd>: Toggle light / dark theme
  - <kbd>←</kbd> / <kbd>↑</kbd>: Increase time (+1s, or +5s with <kbd>Shift</kbd>)
  - <kbd>→</kbd> / <kbd>↓</kbd>: Decrease time (-1s, or -5s with <kbd>Shift</kbd>)
