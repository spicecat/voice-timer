# Voice Timer

A custom timer with voice cues.

## Features

- **High-precision timing**: Sub-second accuracy.
- **Voice cues**: Spoken countdowns.
- **Visual feedback**: Continuous circular progress.
- **Customizable**: Multi-loop and multi-segment routines.
- **Convenient**: Keyboard shortcuts, language support, and persistence.

## Development

```bash
# Start development server
npm run dev

# Build for production
npm run build
```
